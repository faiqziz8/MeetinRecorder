Transkrip dari file rekaman

Upload rekaman (Voice Memos, voice note WhatsApp, .m4a, .mp3, .wav, video). Diproses di perangkat ini, gratis, dan file tidak dikirim ke mana pun.

Bahasa mengikuti pilihan Bahasa rapat di atas.
Rekaman ini lebih dari 30 menit. Di HP bisa kehabisan memori atau sangat lama; pakai laptop atau potong rekamannya.

Pemakaian pertama mengunduh model pengenal suara (sekitar 80 MB untuk Cepat, 250 MB untuk Akurat), jadi pakai WiFi. Biarkan layar menyala selama proses. Hasil kurang bagus untuk ruangan bising dan istilah teknis.

Transkrip langsung

Hasil rekaman

  1. Tekan Salin untuk Notulen.
  2. Buka aplikasi Meja Kerja, pilih menu Notulen (ikon mikrofon di bawah), tempel, lalu tekan Buat notulen.
  3. Ringkasan, keputusan, tindak lanjut, dan tebakan pembicara akan muncul di sana.

Riwayat rekaman

Tersimpan hanya di browser HP ini. Sesekali unduh backup lewat Pengaturan.
